DBDesktop Bridge v0.2.6 设备管理

新手指引.

  1. 1

    手动添加 MCP 连接

    当前通过手动配置连接。打开 ChatGPT「插件」页，选择「添加 → 添加自定义 MCP 服务器」，填写以下内容：

    名称：Desktop Bridge
    服务器地址：https://mcp.ilovestudy.de/mcp
    认证方式：OAuth

    打开 ChatGPT 插件页 ↗
  2. 2

    登录并授权

    创建连接后，按提示使用自己的 Google 账号登录并确认授权。首次登录会创建独立账号。授权完成后，继续安装电脑端客户端并确认设备绑定。

  3. 3

    安装电脑端（两种方式任选一种）

    以下两种方式都能安装并配对 Desktop Bridge。安装时使用第 2 步的同一个账号，在配对网页核对电脑名称并确认绑定。

    方式一：图形安装器

    不需要预先安装 Node.js。下载对应系统的安装器，按提示选择手动或后台运行，保持安装窗口打开直到完成。

    Windows 安装器Mac 安装器Linux 安装器

    方式二：npm 命令行

    适合已经安装 Node.js 24 和 npm 的用户；当前 npm 公开版本为 0.2.7。在电脑终端依次执行：

    npm install -g @justlovepl/desktop-bridge
desktop-bridge setup
desktop-bridge status

    npm install 仅安装 CLI；setup 才会安装客户端并引导配对。默认后台模式。首次安装要使用手动模式，可将第二条替换为 desktop-bridge setup --mode manual。

    更多命令：启动、停止、切换模式与升级 
    desktop-bridge start
desktop-bridge stop
desktop-bridge restart
desktop-bridge mode manual
desktop-bridge mode background
desktop-bridge update
desktop-bridge pair

    update 更新 CLI 与已安装的 Agent，保留配对和模式；pair 需要本人再次确认设备绑定。

    两种方式只选一种，无需重复安装。配对码有效期为 10 分钟，完成网页确认后再关闭安装窗口。

  4. 4

    回到 ChatGPT 使用

    在新对话中输入 @，选择你刚创建的 Desktop Bridge 连接，再发送：

    列出我的电脑，检查它是否可用。

    确认「工具可用」后，就可以让 GPT 查看文件或执行任务。以后保持电脑开机、联网、客户端运行即可。

安装说明与常见问题

为什么授权后还要安装电脑端客户端？

MCP 连接负责让 ChatGPT 访问服务，电脑端客户端负责接收并执行任务。首次可以使用图形安装器或 npm，随后由本人确认设备绑定。

每个人都要用自己的账号吗？

是。每个人都在自己的 ChatGPT 中添加 MCP 服务器，并在 OAuth 授权和电脑配对时使用自己的同一个 Google 账号。

系统阻止安装怎么办？

当前是测试分发版。Windows 安装器未签名，Mac 安装包未签名、公证，系统可能阻止打开。请保留完整提示并联系提供此页面的人；安装器不会自动关闭系统防护。

npm 命令找不到怎么办？

先确认 Node.js 主版本是 24，系统有 npm，并且已经重新打开终端。执行 node -v 和 npm -v 检查环境。

Linux 可以直接双击吗？

Linux 文件管理器的行为不同。桌面支持时选择「在终端中运行」；否则需要通过 shell 运行下载的自解包脚本。

GPT 看不到我的电脑

先确认安装窗口已显示完成，配对网页与 GPT 登录的是同一个账号，电脑保持联网，再让 GPT 检查设备。如果已绑定但离线，启动原有客户端，无需反复安装。

配对码过期怎么办？

配对码有效期为 10 分钟。尚未绑定时，重新运行图形安装器的配对流程，或使用 desktop-bridge pair 重新配对。已完成绑定后，请在设备管理页检查设备状态，旧配对码不能用于检查连接是否正常。

找不到「添加自定义 MCP 服务器」怎么办？

请先确认当前账号或工作空间允许创建自定义 MCP 连接。若由组织管理，请联系管理员检查相关权限。
