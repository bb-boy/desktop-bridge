DBDesktop Bridge v0.2.4 设备管理

在 GPT 中使用你的电脑.

  1. 1

    上传 GPT 插件

    下载 ZIP，不用解压。在 ChatGPT 网页的「插件 → 添加 → 上传插件压缩包」中上传。

    下载 GPT 插件 ZIP打开 ChatGPT 插件页 ↗
  2. 2

    连接你的账号

    在 ChatGPT 中连接 Desktop Bridge，使用自己的 Google 账号登录，并确认授权。首次登录会创建独立账号。

  3. 3

    在要控制的电脑上安装

    下载对应系统的安装器并打开。它会自动准备 Node.js 和 Desktop Commander，再打开配对网页。用第 2 步的同一个账号登录，核对电脑名称并确认绑定。

    Windows 安装器Mac 安装器Linux 安装器
  4. 4

    回到 GPT 使用

    在对话中输入 @，选择 Desktop Bridge，再发送：

    列出我的电脑，检查它是否可用。

    确认「工具可用」后，就可以让 GPT 查看文件或执行任务。以后保持电脑开机、联网、客户端运行即可。

安装说明与常见问题

为什么还要打开电脑端安装器？

GPT 插件负责连接对话与服务。电脑端安装器负责让你自己的电脑接收任务。首次需要本人打开一次，后续环境准备自动完成，不需要安装 ChatGPT 桌面版。

每个人都要用自己的账号吗？

是。每个人在 GPT 连接插件和电脑配对时都使用自己的同一个 Google 账号。不需要服务提供者的密码、邀请或设备密钥，也不应使用别人的账号。

系统阻止安装怎么办？

当前是测试分发版。Windows 安装器未签名，Mac 安装包未签名、公证，系统可能阻止打开。请保留完整提示并联系提供此页面的人；安装器不会自动关闭系统防护。

Linux 可以直接双击吗？

Linux 文件管理器的行为不同。桌面支持时选择「在终端中运行」；否则需要通过 shell 运行下载的自解包脚本。

GPT 看不到我的电脑

先确认安装窗口已显示完成，配对网页与 GPT 登录的是同一个账号，电脑保持联网，再让 GPT 检查设备。如果已绑定但离线，启动原有客户端，无需反复安装。

上传失败

重新下载本页的最新 ZIP，再尝试上传。不要重复使用旧文件，也不要使用服务提供者的私人插件链接。保留错误提示，便于排查。网页首次上传、真实账号登录与图形安装仍需在使用者的设备上验收。
